# Crystals and Dragons

Текстовая RPG для iOS. Игрок ходит по лабиринту, собирает предметы и ищет сокровище.

![Screenshot](ScreenshotOfGame.png)

## Как играть

Цель - найти ключ и сундук, открыть его и забрать Грааль. Управление текстовыми командами:
- `n/s/w/e` - движение
- `get [предмет]` - взять предмет
- `drop [предмет]` - выбросить
- `open` - открыть сундук (нужен ключ)
- `eat [еда]` - восстановить здоровье
- `fight` - атаковать монстра (нужен меч)

## Фичи

- Процедурная генерация лабиринта
- Тёмные комнаты (нужен факел)
- Монстры и боевая система
- Золото и предметы
- Лимит ходов

## Запуск

Открыть в Xcode и запустить. Требуется iOS 15+.

## Архитектура

MVVM на SwiftUI. Никаких сторонних библиотек.
```
Models → GameEngine → ViewModel → View
```

Лабиринт генерируется через DFS, проверяется проходимость через BFS.
